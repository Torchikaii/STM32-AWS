# STM32-AWS

CI/CD pipeline for STM32 projects with STM32CubeMX automation.

## Quick Start

See [docs/getting-started.md](docs/getting-started.md)

## What This Does

- Generates STM32 code from CubeMX .ioc files
- Compiles with ARM GCC
- Flashes to STM32F439 MCU
